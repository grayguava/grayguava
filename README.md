### What's here

- Repos that exist to work, not to look polished
- Notes left behind so future-me doesn't have to figure it out twice

**Main projects**
- **formseal**: server-blind encrypted form submissions. A browser embed encrypts with X25519, a CLI fetches the ciphertexts, and an offline CLI decrypts them locally. No hosted service, no backend trust.
- **Libreprobe**: self-hosted connection stability test. It probes 6 endpoints and reports latency against baseline bands.
- **TinyScripts**: my org for small portable Windows tools, each a single .exe built with the compiler that ships with Windows.
